# Ferhan Büyükçolak — Homepage

Static homepage for `https://ferhannb.github.io/`.

To publish, create a public repository named **exactly** `ferhannb.github.io` under GitHub account `ferhannb`, upload `index.html` and `.nojekyll` to its root, then in Settings → Pages choose Deploy from a branch → main → /(root).

The original Python DD-NMPC research code is not included.
